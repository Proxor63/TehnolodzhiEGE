# ТехнолоджиЕГЭ

Интерактивный тренажёр по информатике для подготовки к ЕГЭ: все 27 заданий, запуск Python прямо в браузере, план подготовки, мини-викторины и чат проекта.

## Как пользоваться

Открой [тренажёр](Prohor.html):

- выбери задание из списка (1–27);
- прочитай теорию и готовый код-подсказку;
- нажми «Запустить» — код выполнится прямо в браузере (Python работает через Pyodide);
- реши задачу, отметь «Я решил(а) ✓» — счётчик решённых сохранится на этом устройстве;
- веди «План на сегодня» и проходи мини-викторину;
- чат внизу — общение по комнате через MQTT (нужен интернет).

## Запуск локально (без интернета)

```bash
python -m http.server 8765
```

и открой `http://localhost:8765/` — весь код и Python-движок (Pyodide) лежат в папке `pyodide/`, интернет не нужен (кроме чата).

## Структура

- `index.html` — главная страница-лендинг
- `Prohor.html` — сам тренажёр
- `pyodide/` — локальная копия Python для браузера (не нужна сеть)
- `vendor/` — библиотека MQTT для чата

## Технологии

- Python (Pyodide — WebAssembly) прямо в браузере
- MQTT (брокер emqx) для чата
- Pure HTML/CSS/JS, без сборки

Сделано с заботой о тех, кто сдаёт ЕГЭ.
